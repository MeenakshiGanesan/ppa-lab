# Experiment 8 – Predictive Model Comparison

## Overview

This project demonstrates and compares three machine learning models:

* Decision Tree
* K-Nearest Neighbors (KNN)
* Neural Network

The models are applied to multiple datasets to evaluate their performance.

---

## Datasets

* Diabetes (Healthcare)
* Child Illiteracy
* Customer Shopping Behavior
* Trade / Market Data

---

## Features

* Data preprocessing and training
* Model evaluation and comparison
* Interactive dashboard using Streamlit
* Visualizations with Plotly

---

## How to Run

```bash
pip install -r requirements.txt
python src/train.py
python -m streamlit run app/dashboard.py
```

---
## Output

* Comparison of model accuracy
* Best model for each dataset
* Interactive charts and insights
